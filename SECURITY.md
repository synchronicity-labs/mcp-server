# Security

## Report a vulnerability

Email **security@sync.so** with what you found, the steps to reproduce it, and what an attacker could do with it.

Do not open a public GitHub issue for a vulnerability. Do not include real user data in the report.

We acknowledge every report and keep you updated until it's resolved. Please give us a reasonable time to fix the issue before you disclose it publicly.

## Scope

This policy covers the MCP server source in this repository, the `@sync.so/mcp-server` npm package, and the hosted MCP server at `https://mcp.sync.so/mcp`. Report issues in the sync. API or [sync.so](https://sync.so) to the same address.
